# البشرى للأخبار — Al-Bushra News

أخبار موثّقة المصدر بالعربية والإنجليزية، مع لوحة أرقام إنسانية تعرض مصدر كل رقم وفترته ونوعه.

**نسخة العرض المباشرة:** `https://aladeen35.github.io/albushra-news/`
تتحدث كل ساعة بأخبار حقيقية من أكثر من 18 مصدرًا، منها واس والعربية والشرق الأوسط وسكاي نيوز عربية والجزيرة وسونا وسودان تربيون وراديو دبنقا وBBC وDW وفرانس 24 والأمم المتحدة.

**لوحة الإدارة:** `https://aladeen35.github.io/albushra-news/#/admin`، وتعمل من الهاتف أيضًا. الدخول برمز GitHub خاص بهذا المستودع (Fine-grained token: صلاحية Contents وActions على Read and write). التعديلات تُحفظ في مجلد `content/` وتظهر بعد إعادة البناء خلال دقائق. انظر [دليل التشغيل](news-observatory/GUIDE-AR.md).

| | |
|---|---|
| التشغيل على جهازك | `news-observatory/start.bat` (ويندوز) أو `news-observatory/start.sh` |
| خادم كامل | `docker compose up -d --build` داخل `news-observatory`، أو Render |
| الشيفرة والتوثيق | [news-observatory/README.md](news-observatory/README.md) |

العناوين والملخصات ملك ناشريها، والأرقام للجهات التي أنتجتها. تفتح كل قصة على موقع ناشرها.
