# تعديلات لوحة الإدارة

تكتب لوحة الإدارة في هذا المجلد عند الحفظ من الموقع (ومن الهاتف)، ويطبّقها البناء الساعي، ويعمل البناء أيضًا فور كل حفظ.

| الملف | المحتوى |
|---|---|
| `articles.json` | أخبار أضافها المحررون |
| `sites.json` | مواقع ووردبريس أو مواقع لها رابط أخبار |
| `hidden.json` | روابط أخبار مخفية |
| `figures.json` | أرقام أدخلها المحررون (بانتظار المراجعة) |
| `approvals.json` | قرارات اعتماد الأرقام أو رفضها |
| `sources.json` | تفعيل المصادر أو إيقافها |

سجل المستودع هو سجل التدقيق: كل تعديل التزامٌ باسم من أجراه. وللتراجع عن تعديل، احذفه من الملف أو استرجع الالتزام.
