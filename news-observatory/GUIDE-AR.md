# دليل تشغيل «البشرى للأخبار»

هذا الدليل لمن يتولى تشغيل المنصة: نشر الموقع، وتثبيت تطبيق أندرويد، والدخول إلى لوحة الإدارة.

---

## أولًا: مكوّنات المنصة

| المكوّن | الوصف |
|---|---|
| **الخادم والموقع** | خدمة واحدة تقدّم الموقع وواجهة البيانات، وتجلب الأخبار والمؤشرات تلقائيًا كل ساعة. |
| **قاعدة البيانات** | PostgreSQL في التشغيل الفعلي، وSQLite للتجربة المحلية. |
| **تطبيق أندرويد** | يفتح الموقع نفسه من الخادم، فيعرض المحتوى ذاته دائمًا دون تحديث للتطبيق. |
| **لوحة الإدارة** | على العنوان `/admin` باسم مستخدم وكلمة مرور. |

يحتاج الخادم إلى اتصال بالإنترنت ليجلب الأخبار. والمصادر التالية تعمل فور التشغيل دون مفاتيح:

- قنوات RSS الرسمية للناشرين: واس، العربية، الشرق الأوسط، الجزيرة، سكاي نيوز عربية، BBC، فرانس 24، DW، سونا، سودان تربيون، راديو دبنقا، والمصادر الرياضية.
- GDELT للأخبار العالمية.
- ReliefWeb عبر RSS للتقارير الإنسانية.

## ثانيًا: نشر الموقع

### الخيار (أ): Render، والأسهل

1. أنشئ حسابًا في [render.com](https://render.com) واربطه بحساب GitHub.
2. من لوحة Render اختر **New ← Blueprint**، ثم المستودع `aladeen35/FSM` والفرع `claude/new-session-z4gw4p`.
3. يقرأ Render الملف `render.yaml`، وينشئ الخدمة وقاعدة البيانات، ويولّد كلمة مرور الإدارة.
4. بعد اكتمال النشر يظهر عنوان الموقع، مثل `https://albushra-news.onrender.com`.
5. كلمة مرور الإدارة: في صفحة الخدمة ← **Environment** ← `ADMIN_PASSWORD`. واسم المستخدم `admin`.

> اخترت في الملف خطة **Starter** للخدمة و**Basic** لقاعدة البيانات، لأن الخطة المجانية توقف الخادم عند الخمول فتتوقف الجلبات الساعية، وقاعدة بياناتها المجانية تنتهي بعد مدة.

### الخيار (ب): خادم خاص (VPS) بـ Docker

```bash
git clone https://github.com/aladeen35/FSM.git
cd FSM/news-observatory
git checkout claude/new-session-z4gw4p
cp .env.example .env        # اضبط ADMIN_PASSWORD و SECRET_KEY و POSTGRES_PASSWORD
docker compose up -d --build
```

يعمل الموقع على المنفذ `8090`. ضع أمامه خادمًا عكسيًا مثل Nginx أو Caddy بشهادة HTTPS، فالتطبيق يتصل عبر HTTPS فقط.

## طرق مجانية للتجربة قبل الدفع

| الطريقة | التكلفة | الإدارة | البيانات | المناسب له |
|---|---|---|---|---|
| **1. على جهازك** (`start.bat` أو `start.sh`) | مجانًا | تعمل | حقيقية وتتحدث كل ساعة | تجربة كاملة الآن |
| **2. جهازك + Cloudflare Tunnel** | مجانًا | تعمل | حقيقية | رابط https للهاتف وتطبيق أندرويد |
| **3. Render (الخطة المجانية)** | مجانًا | تعمل | حقيقية، وتُمسح عند إعادة التشغيل | رابط عام دائم للتجربة |
| **4. Hugging Face Spaces** | مجانًا | تعمل | حقيقية، وتُمسح عند إعادة التشغيل | رابط عام بديل |
| **5. GitHub Pages** | مجانًا لمستودع عام | لا (قراءة فقط) | لقطة حقيقية تتجدد كل ساعة | عرض الموقع للآخرين |

### 1) التشغيل على جهازك

- **ويندوز:** ثبّت [Python](https://www.python.org/downloads/) مع تحديد «Add to PATH»، ثم انقر مرتين على `news-observatory/start.bat`.
- **ماك ولينكس:** في الطرفية اكتب `./news-observatory/start.sh`.
- يطلب البرنامج كلمة مرور للإدارة، ثم يفتح الموقع على `http://localhost:8000`، والإدارة على `http://localhost:8000/admin`.
- يجلب الأخبار فورًا ثم كل ساعة، ما دام البرنامج يعمل.

### 2) رابط عام من جهازك (للهاتف وتطبيق أندرويد)

1. ثبّت [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)، وهو مجاني ولا يحتاج حسابًا.
2. والموقع يعمل، افتح نافذة أخرى واكتب:
   ```
   cloudflared tunnel --url http://localhost:8000
   ```
3. يظهر رابط مثل `https://xxxx.trycloudflare.com`. افتحه من أي هاتف، أو أدخله في تطبيق أندرويد عند أول تشغيل.
4. يبقى الرابط صالحًا ما دام جهازك والأمر يعملان.

### 3) Render مجانًا

- New ← Blueprint ← المستودع والفرع، ثم في «Blueprint path» اكتب `news-observatory/deploy/render-free.yaml`.
- كلمة مرور الإدارة: Environment ← `ADMIN_PASSWORD`.
- يتوقف الخادم بعد 15 دقيقة بلا زيارات، ويستيقظ عند الزيارة التالية خلال نحو دقيقة ويجلب الأخبار فورًا.
- البيانات مؤقتة، تكفي للتجربة. وعند الاقتناع انتقل إلى `render.yaml` المدفوع.

### 4) Hugging Face Spaces

اتبع `news-observatory/deploy/huggingface/README.md`: أنشئ مساحة Docker، وارفع الملفات المذكورة، وأضف السر `ADMIN_PASSWORD`.

### 5) GitHub Pages (قراءة فقط)

- **القيد:** المستودع الحالي خاص، وصفحات GitHub للمستودعات الخاصة تحتاج اشتراكًا مدفوعًا.
- **المجاني:** مستودع **عام** يحتوي مجلد `news-observatory`، مع نسخ `deploy/github-pages.yml` إلى `.github/workflows/`، ثم Settings ← Pages ← Source: GitHub Actions.
- **ما تحصل عليه:** موقع على `https://<اسمك>.github.io/<المستودع>/` يعيد جلب الأخبار وبناء الصفحات كل ساعة.
- **ما يعمل فيه:** القراءة والأقسام والبحث والفلاتر وصفحة «لك» في المتصفح.
- **ما لا يعمل فيه:** الإدارة، فلا خادم خلفه. وصفحة «الإدارة» تقول ذلك صراحة.
- **تنبيه:** لا تنسخ مجلد `android/keystore` إلى مستودع عام.

## ثالثًا: لوحة الإدارة

- **العنوان:** `https://<عنوان-موقعك>/admin`، أو الرابط «الإدارة» في تذييل كل صفحة.
- **الدخول:** اسم المستخدم (`ADMIN_USERNAME`، افتراضيًا `admin`) وكلمة المرور (`ADMIN_PASSWORD`).
- **الأمان:**
  - تستمر الجلسة 12 ساعة.
  - خمس محاولات خاطئة توقف الدخول 15 دقيقة.
  - لا تعمل اللوحة إطلاقًا إذا لم تُضبط كلمة المرور.

| التبويب | الاستخدام |
|---|---|
| المراقبة | حالة كل مصدر: آخر نجاح وآخر خطأ وزمن الاستجابة والحصة، وحالة المؤشرات، وزرّا «جلب الآن». |
| إضافة موقع | الصق عنوان أي موقع، ووردبريس أو غيره. يعرض آخر المنشورات، ثم يُحفظ ويُجلب كل ساعة. |
| إضافة خبر | خبر يدوي بعنوانه ورابطه وملخصه، ويُصنَّف آليًا إن تُركت الدول والموضوعات فارغة. |
| قائمة المراجعة | اعتماد الأرقام قبل ظهورها. لا يعتمد الرقمَ مَن أدخله. |
| إدخال رقم | إدخال رقم من تقرير رسمي مع الرابط والفترة ونوع الرقم. |
| بيانات HDX | البحث في فهرس البيانات الإنسانية مع الرخصة والجهة. |
| المصادر | تفعيل المصادر وإيقافها، وتأكيد مراجعة شروطها، والسماح بالصور. |
| قوائم الدول / الأزمات | تعديل تعريف «العالم العربي» و«العالم الإسلامي»، وإضافة أزمات جديدة. |

## رابعًا: تطبيق أندرويد

- يُبنى تلقائيًا في GitHub Actions، ويُنشر في **Releases** باسم «البشرى للأخبار 1.0.N».
- **التثبيت:**
  1. نزّل `albushra-news.apk` على الهاتف وافتحه.
  2. اسمح بالتثبيت من هذا المصدر عند الطلب.
- **أول تشغيل:** يطلب التطبيق عنوان الخادم، مثل `https://albushra-news.onrender.com`، ويحفظه.
- **تغيير الخادم لاحقًا:** من «الإعدادات» داخل التطبيق، أو من شاشة تعذّر الاتصال.
- **بناء نسخة بعنوان مضمَّن:** من Actions ← «البشرى للأخبار — بناء تطبيق أندرويد» ← **Run workflow**، مع إدخال العنوان. أو اضبط متغير المستودع `NEWS_SERVER_URL`.
- **التحديثات:** كل نسخة تُثبَّت فوق السابقة، لأنها موقّعة بالمفتاح نفسه.
- **المعرّف:** `sa.albushra.news`، فلا يتعارض مع تطبيق «بشرى» للمصحف.

> **للنشر في Google Play:** ولّد مفتاحًا خاصًا بك وضعه في أسرار المستودع (`NEWS_KEYSTORE_PATH` وكلمات المرور). المفتاح المضمَّن في المستودع للتوزيع المباشر فقط.

## خامسًا: مصادر البيانات وإعداداتها

| المتغير | الغرض | بدونه |
|---|---|---|
| `HDX_APP_NAME` + `HDX_APP_EMAIL` | مؤشرات HDX HAPI (النزوح، المحتاجون للمساعدة) | تبقى هذه المؤشرات بلا بيانات |
| `DTM_SUBSCRIPTION_KEY` | بيانات النزوح من IOM مباشرة | يُستعمل HDX HAPI بديلًا |
| `RELIEFWEB_APPNAME` | تقارير ReliefWeb عبر واجهته البرمجية | يُكتفى بقناة RSS |
| `GNEWS_API_KEY` وغيرها | مزودو أخبار إضافيون | تكفي المصادر المجانية |

كل رقم يصل من مصدر آلي ينتظر في «قائمة المراجعة» حتى يعتمده محرر. ولا يُعرض رقم بلا مصدر وفترة ووحدة.

## سادسًا: التحقق من التشغيل

آخر فحص بالبيانات الحقيقية محفوظ في `docs/screenshots/`: التقرير `live-report.md` وصور الصفحات. وفيه نحو ألف خبر حقيقي من أكثر من 18 مصدرًا، ورقما HDX HAPI للسودان (النازحون داخليًا والمحتاجون للمساعدة) بانتظار المراجعة.


ورشة «البشرى للأخبار — اختبار وفحص البيانات الحقيقية» في GitHub Actions:

1. تشغّل الاختبارات الآلية كلها.
2. تجلب الأخبار من المصادر الحقيقية عبر الإنترنت، وتنشر تقريرًا بعدد الأخبار من كل مصدر، مع عينات من العناوين وروابطها.
3. تشغّل الموقع وتلتقط صورًا لصفحاته ببيانات حقيقية.
4. تبني صورة Docker وتتأكد من عمل الموقع والدخول إلى الإدارة.
